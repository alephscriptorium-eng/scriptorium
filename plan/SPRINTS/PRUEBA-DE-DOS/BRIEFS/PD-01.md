## CA

1. `playground/prueba-de-dos/` entra a git como starter kit: `SKILL.md`,
   `manual.md`, `handoffs/handoff-H.md` + `handoffs/handoff-M.md`,
   `scripts/generar.mjs`, `reference/PEERCARD.md`, `package.json`,
   `.npmrc`, `.gitignore`.
2. `npm run generate A_B` crea `H/` (operador A) y `M/` (operador B)
   npm-inicializadas con el stack que validó H
   (authority-kit · ciudad · presets-sdk · protocol · rooms ·
   socket-server · startpack-ciudad · startpack-kit).
3. Generador idempotente: no pisa ficheros con contenido; `--sin-install`
   disponible.
4. `H/` y `M/` regenerables = gitignoradas; el kit las recrea.
5. Manual con criterios de **experiencia** (§5), no de arranque.
